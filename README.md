# 🎬 Netflix Clone

A responsive **Netflix-inspired website** built using **HTML and CSS**. This project recreates the look and feel of Netflix with a modern dark-themed interface, cinematic visuals, and a clean layout.

## 🌟 Features

* 🎨 Modern Netflix-inspired UI
* 🌑 Dark-themed design
* 🎥 Cinematic hero section
* 🧭 Navigation bar with Sign In button
* 🍿 Trending movies section with posters
* 📱 Responsive layout for different screen sizes
* ✉️ Email input section for getting started

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling, layout, and visual effects

## 📸 Project Preview

The website features a Netflix-inspired landing page with a dark background, movie posters, and a cinematic design.

## 🚀 Getting Started

Follow these steps to run the project locally:

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! 🎉
